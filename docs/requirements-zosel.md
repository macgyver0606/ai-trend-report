# 뉴스 & 트렌드 리포트 생성기 요구사항 정의서

> 상태: 초안
> 최종 수정일: 2026-07-25
> 확정 전 항목은 프로젝트 진행 중 논의 후 갱신한다.

## 1. 프로젝트 개요

- 프로젝트명: 마케터 & 기획자를 위한 「뉴스 & 트렌드 리포트 생성기」
- 프로젝트 목적: 공개된 언론사 RSS와 AI 분석을 활용해 산업·경쟁사의 변화 및 시장 트렌드를 근거 기반 리포트로 제공한다.
- 대상 사용자: 산업과 경쟁사 동향을 파악해야 하는 마케터 및 기획자
- 해결하려는 문제: 여러 언론사 기사를 직접 찾아 읽고 비교·요약하는 데 드는 시간을 줄인다.

## 2. MVP 목표

사용자가 **자유 입력 키워드, 산업, 상위 주요 기업 수, 검색 기간을 먼저 입력**하면, 시스템이 연합뉴스 RSS에서 관련 경쟁사 뉴스를 수집하고 LLM으로 분석하여 트렌드 리포트를 제공한다. 검색 기간은 최근 한 달을 기본으로 하며 1주일~3개월 범위에서 직접 선택할 수 있다. 최근 한 달 리포트에는 주차별 변화와 분석 설정, 각 내용의 인용·출처를 함께 표시한다.

MVP 이후 기능은 로그인, 사용자별 저장·공유, 고급 검색·추천, 관리자 페이지, 자동 알림 발송으로 둔다.

## 3. 핵심 사용자 흐름

1. 시스템은 사용자에게 자유 입력 키워드, 산업, 상위 주요 기업 수, 검색 기간을 입력하도록 요청한다.
2. 사용자가 설정을 입력하고 분석을 요청한다.
3. 시스템은 DART 사업보고서의 최근 사업연도 연결 재무제표 매출액을 기준으로 상위 N개 경쟁사를 정하고, 지정 기간의 연합뉴스 RSS에서 키워드와 관련된 뉴스를 수집한다.
4. 시스템은 수집 결과 중 검색 노출 상위 5개 기사를 우선 분석 대상으로 선정한다.
5. 시스템은 선정된 RSS 기사 데이터를 LLM에 전달해 키워드 출현 빈도를 기반으로 핵심 내용을 분석하고 트렌드를 정의한다.
6. 시스템은 전체 요약, 주차별 분석, 정의된 트렌드, 인용·출처, 분석 설정을 포함한 리포트를 표시한다.
7. 사용자는 기사별 원문 출처를 열어 근거를 확인한다.

## 4. 기능 요구사항

| ID | 요구사항 | 우선순위 | 수용 기준 |
| --- | --- | --- | --- |
| FR-01 | 분석 시작 전 자유 입력 키워드, 산업, 상위 주요 기업 수, 검색 기간을 사용자에게 입력받는다. | 필수 | 검색 기간의 기본값은 최근 한 달이며, 1주일~3개월 범위를 벗어나거나 필수값이 없으면 분석을 시작하지 않고 안내한다. |
| FR-02 | DART 사업보고서의 최근 사업연도 연결 재무제표 매출액을 기준으로 산업별 상위 N개 경쟁사를 분석 범위로 설정한다. | 필수 | 선택한 산업의 기업별 매출액 기준과 기준 사업연도를 확인할 수 있다. |
| FR-03 | 연합뉴스 RSS를 참조하여 설정 키워드 및 경쟁사와 관련된 뉴스를 수집한다. | 필수 | 수집 항목에 기사 제목, 발행일, 언론사명(연합뉴스), 원문 URL이 포함된다. |
| FR-04 | 수집된 검색 결과 중 노출 상위 5개 기사를 분석 대상으로 선정한다. | 필수 | 분석 대상 기사 수가 5개 미만이면 확보된 기사 수와 부족 사실을 표시한다. |
| FR-05 | 수집된 RSS 기사 데이터를 기반으로 LLM이 키워드 출현 빈도를 분석하고 트렌드를 정의한다. | 필수 | 리포트에 기사 요약, 키워드 빈도, 하나 이상의 트렌드 정의가 표시되며, 분석 대상이 없으면 빈 상태를 안내한다. |
| FR-06 | 최근 한 달의 분석 결과를 1주차부터 4주차까지 구분해 표시한다. | 필수 | 최근 한 달 선택 시 각 주차에 분석 내용을 표시하며, 해당 주에 기사가 없으면 빈 상태를 표시한다. 그 외 기간은 기간 전체 요약을 표시한다. |
| FR-07 | 리포트 요약 하단에 분석 설정을 지정 형식으로 표시한다. | 필수 | `설정 키워드: {키워드}`와 `산업: {산업} | 상위 주요 기업: {N}개 | 검색 기간: YYYY-MM-DD ~ YYYY-MM-DD | 빈도수: N회`를 표시한다. |
| FR-08 | 리포트의 주장·요약에 인용 또는 출처를 표기한다. | 필수 | 각 인용·출처에서 언론사명, 기사 제목, 발행일, 원문 URL을 확인할 수 있다. |
| FR-09 | 원문 출처 링크를 열 수 있다. | 필수 | 유효한 원문 URL을 통해 해당 기사를 새 페이지 또는 탭에서 열 수 있다. |
| FR-10 | RSS 수집·LLM 분석 실패, 빈 결과를 사용자에게 안내한다. | 필수 | 실패 원인 또는 빈 상태를 표시하고 기존 화면이 중단되지 않는다. |

## 5. 데이터 및 분석 기준

- 뉴스 데이터의 1차 출처는 연합뉴스가 공개한 RSS로 제한한다.
- 경쟁사 범위는 사용자가 선택한 산업의 매출 기준 상위 N개 기업으로 정한다. 매출 기준 데이터는 DART 사업보고서의 최근 사업연도 연결 재무제표 매출액을 사용한다.
- RSS 항목에서 제목, 요약 또는 본문 제공 범위, 발행일, 언론사명, 원문 URL을 추출한다.
- 검색 결과의 노출 상위 5개 기사를 기본 분석 대상으로 한다. 5개보다 적으면 수집된 전체 기사를 분석한다.
- LLM은 RSS에서 추출한 데이터만을 분석 근거로 사용하며, 키워드 출현 빈도를 트렌드 정의의 핵심 기준으로 사용한다. 분석 결과에는 사실과 해석을 구분하고, 근거가 되는 출처를 연결한다.
- 동일 기사의 중복 수집 여부와 키워드 매칭 규칙은 기능 분해 단계에서 정한다.
- LLM 또는 RSS 서비스의 API 키는 환경 변수로 관리하며 실제 값은 코드·문서·로그에 기록하지 않는다.

## 6. 리포트 출력 기준

리포트에는 최소한 다음을 포함한다.

1. 설정 키워드, 산업, 상위 주요 기업 수, 검색 기간
2. 핵심 요약, 키워드 출현 빈도, LLM이 정의한 트렌드
3. 최근 한 달 선택 시 주차별 분석: `1주차`, `2주차`, `3주차`, `4주차` (그 외 기간은 기간 전체 요약)
4. 근거 기사 목록과 인용·출처
5. 요약 내용 하단의 설정 정보: `설정 키워드: {키워드}` 및 `산업: {산업} | 상위 주요 기업: {N}개 | 검색 기간: YYYY-MM-DD ~ YYYY-MM-DD | 빈도수: N회`

여기서 빈도수는 해당 조건으로 수집되어 분석에 사용된 RSS 기사 건수를 뜻한다. 검색 기간의 기본값은 최근 한 달이며, 직접 선택 가능한 범위는 1주일~3개월이다.

## 7. 비기능 및 보안 요구사항

- 한국어 중심의 읽기 쉬운 리포트를 제공한다.
- 원문 URL 누락, RSS 응답 오류, LLM 분석 실패에도 화면이 중단되지 않아야 한다.
- API 키, 인증 정보, 개인정보를 코드·문서·로그에 기록하거나 노출하지 않는다.
- RSS 콘텐츠의 이용 조건과 저작권을 확인하고, 리포트에는 원문 전체 대신 필요한 범위의 요약과 출처를 제공한다.

## 8. 확정 내역

다음 항목은 확정됐다.

- RSS 출처: 연합뉴스
- 경쟁사 범위: DART 사업보고서의 최근 사업연도 연결 재무제표 매출액 기준 산업별 상위 N개
- 키워드 입력: 자유 입력
- 분석 기간: 최근 한 달 기본값, 사용자가 1주일~3개월 범위에서 직접 선택
- 기간별 표시: 최근 한 달은 1주차~4주차 변화 표시, 그 외 기간은 기간 전체 요약
- 분석 대상: 검색 노출 상위 5개 기사
- 트렌드 정의 기준: 키워드 출현 빈도
- 최종 제출물: 웹서비스
