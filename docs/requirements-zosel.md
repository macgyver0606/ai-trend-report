# AI 트렌드 리포트 요구사항 정의서

> 상태: 초안
> 작성일: 2026-07-23
> 확정 전 항목은 프로젝트 진행 중 논의 후 갱신한다.

## 1. 프로젝트 개요

- 프로젝트명: AI 트렌드 리포트 *(폴더명 `ai-trend-report` 기준 임시명)*
- 프로젝트 목적: AI 관련 동향 정보를 사용자가 빠르게 이해할 수 있는 리포트 형태로 제공한다.
- 대상 사용자: AI 동향을 정기적으로 확인하려는 학습자 또는 실무자 *(확정 필요)*
- 해결하려는 문제: 여러 출처에 흩어진 AI 관련 정보를 탐색·정리하는 데 드는 시간을 줄인다.

## 2. MVP 목표

사용자가 한 화면 또는 한 개의 리포트에서 최신 AI 동향의 핵심 내용을 확인할 수 있게 한다. MVP는 **정보 수집, 핵심 내용 정리, 리포트 표시**의 최소 흐름을 우선 검증한다.

다음 항목은 MVP 이후로 둔다.

- 로그인과 사용자별 설정
- 관리자 페이지
- 고급 검색·추천 기능
- 자동 배포 및 알림 발송

## 3. 핵심 사용자 흐름

1. 사용자가 AI 트렌드 리포트 화면을 연다.
2. 시스템이 정리된 트렌드 항목 목록을 보여 준다.
3. 사용자가 항목의 제목, 요약, 출처, 발행일을 확인한다.
4. 사용자가 필요하면 원문 출처로 이동한다.

## 4. 기능 요구사항

| ID | 요구사항 | 우선순위 | 수용 기준 |
| --- | --- | --- | --- |
| FR-01 | 트렌드 항목을 목록으로 표시한다. | 필수 | 제목과 요약이 각 항목에 표시된다. |
| FR-02 | 각 항목에 출처와 발행일을 표시한다. | 필수 | 출처 정보가 없으면 누락 사실을 명확히 표시한다. |
| FR-03 | 사용자가 원문 링크를 열 수 있다. | 필수 | 유효한 링크는 새 페이지 또는 탭에서 열 수 있다. |
| FR-04 | 리포트 데이터가 없거나 불러오기에 실패한 경우 안내한다. | 필수 | 빈 화면 대신 오류 또는 빈 상태 메시지를 표시한다. |
| FR-05 | 주제·기간별 필터를 제공한다. | 보류 | MVP 사용성 검증 후 필요 시 추가한다. |

## 5. 데이터 및 제약사항

- 데이터 출처, 수집 방식(수동 입력·RSS·외부 API), 갱신 주기, 저작권·이용 조건은 아직 확정되지 않았다.
- 외부 API를 사용할 경우 API 키는 환경 변수로 관리하며, 실제 값은 코드·문서·로그에 기록하지 않는다.
- 리포트에는 최소한 제목, 요약, 출처명, 원문 URL, 발행일을 포함한다.

## 6. 비기능 요구사항

- 읽기 쉬운 한국어 중심의 화면과 문구를 제공한다.
- 원문 URL이 없거나 데이터가 비정상이어도 화면이 중단되지 않아야 한다.
- 개인정보, 인증 정보, API 키를 저장하거나 노출하지 않는다.
- 모바일·데스크톱 지원 범위와 접근성 기준은 MVP 설계 단계에서 결정한다.

## 7. 확정이 필요한 질문

1. 주요 사용자는 학습자, 일반 사용자, 또는 실무자 중 누구인가?
2. 리포트에서 다룰 AI 주제와 데이터 출처는 무엇인가?
3. 트렌드 정보는 누가·어떤 방식으로 수집하며, 갱신 주기는 얼마인가?
4. 최종 제출물과 평가 기준은 무엇인가?
5. 웹 화면, 문서형 리포트, 또는 둘 다를 제공할 것인가?
