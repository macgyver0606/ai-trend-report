# AI 트렌드 리포트 요구사항 정의서

- 상태: 초안

## 2. 서비스 개요

AI 트렌드 리포트는 여러 AI 관련 뉴스와 콘텐츠에서 핵심 동향을 빠르게 파악할 수 있도록, 최근 정보를 주제별로 수집·요약하여 보여 주는 웹 서비스이다. 사용자는 긴 원문을 모두 읽지 않아도 제목, 핵심 요약, 출처, 발행일을 통해 관심 있는 AI 이슈를 확인하고 원문으로 이동할 수 있다.

## 3. 문제 정의

AI 산업의 변화 속도가 빨라 뉴스, 기업 발표, 연구 동향이 여러 채널에 흩어져 있다. AI에 관심 있는 사용자는 다음과 같은 어려움을 겪는다.

- 신뢰할 수 있는 최신 정보를 골라내는 데 시간이 많이 든다.
- 여러 기사를 읽어도 핵심 변화와 영향이 한눈에 정리되지 않는다.
- 관심 분야별로 정보를 탐색하고 원문을 확인하는 과정이 번거롭다.

본 서비스는 최신 AI 이슈를 읽기 쉬운 카드형 리포트로 제공해 정보 탐색 시간을 줄이는 것을 목표로 한다.

## 4. 대상 사용자

| 사용자 | 주요 상황 | 필요 가치 |
| --- | --- | --- |
| AI 입문자·학생 | AI 산업과 기술 흐름을 학습하려고 함 | 어려운 원문 대신 핵심 요약을 빠르게 확인 |
| 기획자·직장인 | 업무에 영향을 줄 AI 변화를 짧은 시간에 파악하려고 함 | 분야별 최신 동향과 출처 제공 |
| AI 관심 일반 사용자 | 관심 주제의 새로운 소식을 놓치고 싶지 않음 | 날짜·키워드 기준 탐색과 원문 연결 |

## 5. 목표 및 성공 기준

### 5.1 서비스 목표

1. 사용자가 최근 AI 트렌드 목록을 한 화면에서 확인할 수 있게 한다.
2. 각 트렌드의 핵심 내용을 짧고 이해하기 쉬운 문장으로 전달한다.
3. 모든 리포트에서 출처와 원문 링크를 제공해 정보의 확인 가능성을 보장한다.

### 5.2 MVP 성공 기준

- 초기 화면에서 최신 트렌드 카드 목록이 정상적으로 표시된다.
- 카드마다 제목, 요약, 카테고리, 발행일, 출처가 표시된다.
- 사용자가 카테고리 또는 키워드로 원하는 트렌드를 찾을 수 있다.
- 사용자가 원문 링크를 클릭하면 해당 출처 페이지로 이동한다.
- 데이터가 없거나 불러오기에 실패했을 때 이해 가능한 안내 문구가 표시된다.

## 6. MVP 기능 요구사항

| ID | 기능 | 입력·처리 | 출력 | 우선순위 |
| --- | --- | --- | --- | --- |
| FR-01 | 트렌드 목록 조회 | 저장된 트렌드 데이터를 최신순으로 조회 | 트렌드 카드 목록 | 필수 |
| FR-02 | 트렌드 요약 표시 | 각 항목의 제목·요약·카테고리·날짜·출처를 조합 | 카드형 요약 정보 | 필수 |
| FR-03 | 카테고리 필터 | 사용자가 카테고리를 선택 | 선택 분야의 카드 목록 | 필수 |
| FR-04 | 키워드 검색 | 사용자가 검색어 입력 | 제목 또는 요약에 일치하는 카드 목록 | 필수 |
| FR-05 | 원문 링크 이동 | 사용자가 출처 또는 더보기 링크 선택 | 새 탭 또는 출처 원문 페이지 | 필수 |
| FR-06 | 빈 상태·오류 안내 | 결과 없음 또는 데이터 로드 실패 감지 | 재검색 또는 새로고침 안내 문구 | 필수 |

## 7. 데이터 요구사항

트렌드 리포트 한 건은 다음 정보를 가진다.

| 필드 | 설명 | 필수 여부 |
| --- | --- | --- |
| id | 항목을 식별하는 고유값 | 필수 |
| title | 트렌드 또는 기사 제목 | 필수 |
| summary | 핵심 내용을 2~3문장으로 요약한 텍스트 | 필수 |
| category | 예: 생성형 AI, 모델, 산업 활용, 정책 | 필수 |
| publishedAt | 원문 발행일 또는 수집일 | 필수 |
| sourceName | 원문 제공처 이름 | 필수 |
| sourceUrl | 사용자가 확인할 수 있는 원문 주소 | 필수 |
| imageUrl | 대표 이미지 주소 | 선택 |

초기 MVP에서는 팀이 검증한 샘플 데이터 또는 사전 수집 데이터를 사용한다. 자동 수집, AI 자동 요약, 개인화 추천은 데이터 품질과 비용 검토 후 후속 단계에서 도입한다.

## 8. 화면 및 사용자 흐름

1. 사용자가 서비스에 접속하면 최신 AI 트렌드 목록을 본다.
2. 사용자는 카테고리를 선택하거나 검색어를 입력해 목록을 좁힌다.
3. 관심 카드에서 제목과 요약, 출처, 발행일을 확인한다.
4. 사용자는 원문 링크를 통해 출처 페이지로 이동한다.
5. 검색 결과가 없으면 서비스는 결과 없음 안내와 검색 조건 변경 방법을 보여 준다.

## 9. 비기능 요구사항

- 사용성: 비전문가도 제목과 요약만으로 내용을 이해할 수 있는 한국어 UI를 제공한다.
- 반응형: 데스크톱과 모바일 화면에서 카드 목록과 검색·필터 기능을 사용할 수 있어야 한다.
- 성능: 초기 MVP의 정적 또는 소규모 데이터 기준으로 목록 화면이 일반적인 네트워크 환경에서 빠르게 표시되어야 한다.
- 접근성: 이미지에는 대체 텍스트를 제공하고, 검색·필터·링크는 키보드로 조작 가능해야 한다.
- 신뢰성: 출처 이름과 원문 링크를 함께 표시하며, 링크가 없거나 유효하지 않은 데이터는 노출하지 않는다.
- 보안: API 키·토큰 등 민감 정보는 코드와 문서에 직접 기록하지 않고 환경 변수로 관리한다.

## 10. 범위 제외 및 후속 검토

다음 항목은 MVP 범위에서 제외한다.

- 사용자 회원가입·로그인과 개인별 관심사 저장
- 실시간 뉴스 자동 수집 및 대규모 크롤링
- 외부 AI API를 이용한 실시간 자동 요약
- 댓글, 좋아요, 공유 등 소셜 기능
- 관리자 전용 데이터 등록·수정 화면
- 푸시 알림, 이메일 구독, 개인화 추천

후속 단계에서는 데이터 수집 주기, 사용할 출처의 이용 약관, 요약 품질 검수 방식, 외부 API 비용과 호출 제한을 검토한다.

## 11. 가정 및 확인이 필요한 사항

- 프로젝트명과 저장소 이름을 근거로 AI 트렌드 정보를 요약·탐색하는 웹 서비스를 가정했다.
- 제공할 언어는 한국어를 기본으로 가정했다.
- 초기 데이터의 출처, 수집 방식, 갱신 주기, 화면 디자인 및 기술 스택은 아직 확정되지 않았다.
- 팀은 다음 단계에서 이 문서를 바탕으로 기능 분해 문서와 MVP 구현 계획을 작성해야 한다.
